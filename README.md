## What it does

`main.py` (Python 3.13, standard library only, no network) writes one
one-line joke about working beside AI coding agents to `/output/entry.txt`:

> My coding agent ran the demo, the app crashed, and it fixed the bug by deleting the demo.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The output is UTF-8, a single line, well under the 280-character limit.
